# Week 2

## w2/ex1 · FTC 年度交友大会

来源：W2.4。提交 `w2/ex1/Main.java`，默认包，只有 `Main` 为 public 顶层类。

### 背景

在遥远的 FFF 星球上，生活着一群无忧无虑的盐汽水。  
每年，这里都会举办一场盛大的年度盛会——FTC（FFF Total Communication）。  
盐汽水们可以在 FTC 上结识各种伙伴。

但 FFF 星球有一条严苛到离谱的 **交友规则**：

如果一只盐汽水连续三年没有结识新伙伴，  
就会被押到海边，接触 **原始胎海之水**，然后溶解，彻底消失。

FFF 星球的盐汽水分为两个性别：**0** 和 **1**。  
每只盐汽水还带有一种属性：**A、B、C、D**。

结交伙伴的规则如下：

- **A 属性**：可以和任何人交友。
- **B 属性**：只跟自己性别相同的盐汽水交友。
- **C 属性**：只跟自己性别不同的盐汽水交友。
- **D 属性**：最特殊。
  - 如果遇到属性相同的人，也就是对方也是 D，直接交友成功。
  - 否则，必须同时满足：
    1. 性别满足 A/B/C 的条件；
    2. 对方身高矮于自己；
    3. 对方魅力值高于自己。

主角是交友大会的**主办人**，是一只三百年一遇的 **D 型 0 性盐汽水**。  
他的身高足足有 **165cm**，而且因为盐汽水星球的“身高锁定诅咒”，这个数字永远不会变化。  
他的魅力值高达 **90**。

可是，主办人已经连续两年交友失败了。  
今年是第三年，也是最后一年。  
如果再失败，他就会接触原始胎海之水，溶解于 FFF 星球的泡沫之海。

今年，FTC 来了一批异乡旅行者。  
这是主办人唯一的机会了……

### 要求

主办人是一只 **D 型 0 性盐汽水**，固定信息如下：

- 性别：0
- 属性：D
- 身高：165
- 魅力：90

今年 FTC 来了 `n` 位异乡旅行者。  
主办人会按照输入顺序，依次尝试与每一位旅行者结交伙伴，直到交友成功或所有旅行者都尝试完毕。

一旦交友成功，立刻停止尝试；如果所有旅行者都无法交友成功，则主办人失败，接触原始胎海之水溶解。

旅行者信息包括：姓名、性别、属性、身高、魅力。

主办人与旅行者交友时，规则如下：

1. 如果旅行者属性为 **D**，则直接交友成功。
2. 否则，根据旅行者属性判断性别条件：
   - 旅行者属性为 **A**：性别条件直接满足。
   - 旅行者属性为 **B**：旅行者性别必须为 **0**。
   - 旅行者属性为 **C**：旅行者性别必须为 **1**。
3. 同时，旅行者还必须满足：
   - 身高 **小于 165**；
   - 魅力 **大于 90**。

只有以上条件全部满足，主办人才能与对方交友成功。

如果成功，第一行输出 `宣布无人罪`，第二行只输出第一个交友成功的旅行者的姓名 `name`。  
如果失败，输出 `罪人舞步旋`。

### 输入

第一行一个整数 `n`，表示旅行者数量，满足 `1 ≤ n < 10`。

接下来 `n` 行，每行表示一个旅行者的信息，格式为：

```text
姓名 性别 属性 身高 魅力
```

其中：

- 姓名：不含空格的字符串；
- 性别：`0` 或 `1`；
- 属性：`A`、`B`、`C`、`D` 之一；
- 身高、魅力：正整数。

### 输出

如果主办人成功交友：

- 第一行输出：`宣布无人罪`
- 第二行只输出第一个交友成功的旅行者的姓名 `name`。

如果主办人失败：

- 第一行输出：`罪人舞步旋`

### 样例

#### 样例 1

输入：

```text
3
提瓦特路人甲 1 A 170 80
枫丹水神 0 C 160 95
纳塔火龙 1 D 155 85
```

输出：

```text
宣布无人罪
纳塔火龙
```

#### 样例 2

输入：

```text
3

```

```text

```

#### 样例 3

```text
提瓦特路人甲 1 A 170 80
枫丹水神 0 C 160 95

纳塔火龙 1 D 155 85
```

输出：

```text
宣布无人罪

```
