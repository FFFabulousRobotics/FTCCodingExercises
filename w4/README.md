# Week 4

## w4/ex1 · 别让 host 变成白开水（40分）

来源：W4。提交 `w4/ex1/Main.java`，默认包，只有 `Main` 为 public 顶层类。

### 背景

host是一瓶体质虚弱的盐汽水，挨打就漏气。他和室友仅剩2瓶药，必须省着用：满血不能浪费，倒下不能复活，两人还不能各算各的库存。请补全 Soda 类，管理他们的生命和共享药水。

### 要求

每个 Soda 对象代表一瓶盐汽水，拥有独立生命 hp；所有对象共享 potions，初始2瓶。

- **Soda(int hp)**：用参数设置当前对象的初始生命，参数保证在0至10之间；创建对象不能重置药水。
- **void hurt(int damage)**：扣除非负整数伤害，生命最低为0，不消耗药水。
- **void heal()**：仅当生命大于0、小于10且有药时，耗1瓶恢复3点生命，最多为10。其余情况生命、药水都不变。
- **void show()**：输出当前对象生命和共享余药，单个空格分隔，输出后换行。

只补全四个方法体，不得修改字段、方法签名或 Main 类。除 show 外的方法不得输出。

### OJ 输入驱动

原题通过固定 Main 调用对象方法。此处提供读取命令的 Main，让 OJ 能用多组输入测试同一个类。保留 Main，补全上方作答类。每个测试用例都启动新的 JVM，共享库存只在同一组命令内共享。

第一行是命令数 q，随后 q 条命令。id 为对象编号。先创建对象，再操作；编号唯一。参数遵守上文范围。输入不会包含未知命令。

| 命令 | 参数 |
| --- | --- |
| `new` | `id hp` |
| `hurt` | `id damage` |
| `heal` | `id` |
| `show` | `id` |

`new` 使用有参构造；若该类只有无参构造，则使用无参构造。`default` 使用无参构造。`show` 调用 show()；其他命令调用同名方法。

对象操作本身产生的输出，按原题要求直接写到标准输出，不打印提示文字。
